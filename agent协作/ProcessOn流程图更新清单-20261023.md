> 配色建议：🟩 新增节点 = 绿色系；🟨 修改文案的节点 = 黄色系；🟥 删除 = 直接删掉节点和它的连线

## 第一步：删除（2 处）

1. **删节点**：「AI 弹窗询问：要保留博主评论吗？」（主页分支上、进工作台之前的那个判断/提示节点）
   - 连它的上下游连线一起删
2. **删连线**：原来「抓取完成 → OCR 整理 → 导出」的**直连箭头**
   - 因为中间要插入两个新节点（见第三步第 5、6 条）

## 第二步：修改文案（3 处）

1. 节点「**分类判断**」（用户发链接后的第一个菱形/判断框）文案改为：
   > **classify 硬判定**（single / profile / invalid / unknown）
   - 补一条新分支说明：invalid / unknown → 「如实告知用户，不误报链接无效」
2. 节点「**单篇抓取（引擎 A）**」产出物文案改为：
   > 产出 **.md 基础稿**（正文+原图+字幕/转写；正式笔记需后续整理）
3. 节点「**抓取完成**」文案改为：
   > **素材抓取完成**（已存至 downloads/；Markdown 尚未生成）

## 第三步：新增节点（7 个，按数据流顺序）

| # | 插入位置 | 节点文字 | 样式 |
|---|---|---|---|
| 1 | 分类判断**之前** | 🧭 **仓库根定位**（env → marker → 向上探测；失败→安装引导三步） | 绿色 |
| 2 | 分类判断**之前**（与 1 同排或上排） | 🧭 **解释器一致性**（脚本用 marker 记录的 Python 跑） | 绿色（可与 1 合并为一个节点） |
| 3 | 主页分支，**仓库根定位之后** | 🧭 **未安装 → 安装引导三步**（clone → install.py → 重启对话；不说链接无效） | 绿色 |
| 4 | 工作台「开始抓取」**之后** | 📊 **抓取中：结构化进度**（进度条 N/M · 成功/失败/跳过 · 当前篇标题） | 绿色 |
| 5 | 节点 4 的分支 | ⏹ **用户停止 → stopped**（抓完当前篇停，已完成保留）→「继续抓取剩余」自动续 | 绿色（黄色描边） |
| 6 | 节点 4 之后（替代原直连） | 📋 **持久结果卡**（四态：素材完成/已停止/部分完成/全部失败；页面级隔离，新窗口不串卡） | 黄色 |
| 7 | 结果卡**之后、导出之前** | 🔮 **生成 Markdown**（图片价值闸门 + OCR 分级；回对话发「生成 Markdown」触发）——标注「P1-A 待实施」 | 黄色虚线框 |

## 第四步：连线关系核对

- 仓库根定位 →（失败）→ 安装引导 → 【结束/回对话】
- 仓库根定位 →（已安装）→ classify → single / profile
- profile → 工作台勾选 → 抓取中 →（停止）→ 已停止 →（继续）→ 抓取中
- 抓取中 →（全部处理完）→ 持久结果卡 → 生成 Markdown → 导入 Obsidian
- 部分完成 →（仅重试失败项）→ 回到抓取中
