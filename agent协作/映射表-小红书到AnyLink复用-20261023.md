# 复用/迁移映射表：xhs-curator → AnyLink2Note

## 0. 复用判定图例

| 标记 | 含义 |
|---|---|
| 🟢 **契约复用（实现责任在 AnyLink）** | 复用的是**契约形状**（环境变量/文件/CLI 参数），代码由 AnyLink 自行实现；xhs 侧不提供共享库，也承诺接口形状稳定 |
| 🟡 **需适配** | 逻辑可搬，但常量（目录、标识、平台判定）或数据结构必须改 |
| 🔴 **不适合复用** | 与 AnyLink 场景冲突（多平台、逐 P 身份、登录前提不同），各自实现 |

**防漂移总原则**（先于细节）：**优先稳定入口调用，不复制源码、不抽公共框架**。
- 入口形态：CLI（`python <repo>/xxx.py --classify ...`）+ HTTP（工作台 API）+ 文件契约（raw.json / stats 契约）
- 若必须复制（判定 🟡🔴 的部分），复制点标注"源版本 commit + 同步条件"，AnyLink 侧**不承诺跟随升级**

### 2.1 单篇 CLI 可调用契约（响应首轮评审意见 1：现行小红书单篇入口的精确调用方式）

| 项 | 内容 |
|---|---|
| 命令 | `python "<xhs仓库>/skill/scripts/fetch_xhs_note.py" "<分享链接/短链/分享文字>" "<输出目录>"` |
| 输出目录控制 | **第二个位置参数**——AnyLink 传自己的目录即可，产物（metadata.json / imgs/ / `<标题>.md`）全部落在该目录，**不污染 xhs runtime**（已核实：脚本无其他写仓库根的副作用） |
| 产出 schema | `<输出目录>/metadata.json`（title/author/desc/stats/tags/image_urls/local_images）+ `imgs/note_XX.jpg` + `<标题>.md`。⚠️ **.md 定位为基础稿**（实测核实：write_markdown 只写正文、原图引用、字幕/转写——**不执行 OCR 与 11 块宿主整理**），不能单独证明 AnyLink 正式笔记完成；正式笔记需 AnyLink 侧后续整理阶段 |
| 可选参数 | `--no-asr`（跳过本地转写）、`--whisper-model <name>`（默认 small）、`--classify`（只分类不抓取） |
| 解释器与版本 | Python 3.10+；必需 `curl_cffi>=0.16.3`；可选 `faster-whisper>=1.0.0` + `av<15`（仅无字幕视频） |
| 副作用声明（已核实并修正） | ① faster-whisper 模型下载到**脚本所在目录**的 `models/`，且**访问 hf-mirror.net 下载**（修正：网络不只小红书域）——稳定入口调用时模型落 xhs 仓库（xhs 侧资产）；复制脚本则落 AnyLink 侧 ② **AnyLink 接入测试必须覆盖该模型下载分支**（不能只检查 runtime 目录）③ 无登录态读取 |
| HTTP/服务依赖 | 无——单篇为纯 CLI，不依赖工作台服务 |

> 以上契约以现行提交为准（`5675140`+）；xhs 侧承诺该 CLI 形状稳定（参数增减只增不改）。

## 6. 已知差异对映射的影响（派工信 §B.3 逐条应答）

| 差异 | 对复用的影响 |
|---|---|
| AnyLink 多平台、B 站单视频也可能需登录 | classify 的 platform 维度要多一层（平台 × 输入类型）；「单篇免登录」不能作为通例——登录决策必须由平台能力矩阵驱动，不能沿用小红书的"单篇一律匿名" |
| 内容身份需逐 P（平台/BV/CID） | 任务记录与 stats 的 note_id 语义 → `content_key`（平台+作品+分P）；断点/去重/续跑全链路按 content_key，不能按 URL |
| 安装标识/解释器/profile/运行目录 | **严禁**指向 xhs-curator：marker 名、skill 目录名、`browser_profile/`、`runtime/jobs/` 全部独立；解释器可共用同一 venv（依赖重合度高），但 marker 记录各自 |
| 单篇快读无需工作台 | 结果卡/进度条只服务多 P 场景；单篇走"直接产物 + 对话告知"，不要引入工作台依赖 |
| 多 P 停止以当前 P 为边界 | stopped 语义 = 当前 P 完成即停；统计需含 `parts_total/parts_done`，验收时要能证明"已完成 P 可独立访问" |
