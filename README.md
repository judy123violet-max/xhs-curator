## 📖 项目简介

一个把小红书笔记采集进 Obsidian 知识库的**可视化流水线**。

两种用法：1.**主页所有发帖批量下载**——把博主主页或搜索结果铺出来给你看，你点到哪篇存哪篇；2.**单篇**——贴一个分享链接直接抓。挑中的笔记会把正文、原图、**博主本人的有效评论**都抓下来；图片里的干货文字逐字转录成可检索的文字——**干货图转文字防重复，界面截图和照片保留**；评论区的寒暄自动过滤，只留有内容的补充。最后按 Obsidian 规范落库，打开就能用。

**适合谁**：把小红书当信息源、需要长期沉淀到知识库的人（求职面经、行业经验、教程干货、竞品观察）。

## 📸 界面预览

![采集工作台](docs/images/picker.jpg)

工作台是一个本地网页，四个入口常驻同一页面：**博主主页 / 关键词搜索 / 单篇导入 / 已抓笔记**。卡片式浏览，支持全选 / 反选 / 仅视频 / 仅图文 / 关键词过滤，抓过的笔记自动打「已抓过」标记；**点卡片 = 勾选**，**点标题或「原文↗」= 在内嵌详情页看原文**（按 `Esc` 或左上角「← 返回列表」回来，勾选不丢）。**单篇导入**：粘贴分享链接（整段分享文字也行）→ 解析 → 一键抓取，抓过的会自动识别。

**说白了就一点**：别的工具是「存」，这个项目是「挑着存、干净地存」——从一个博主的主页里把值得存的挑出来，连图里的干货和评论区的补充一起洗干净再入仓。

### 这些事，同类项目大多没做

翻过上面几个项目的源码和文档，这三处差异最明显：

1. **图里的字读出来，还做取舍** —— 同行普遍「只下图、不识字」（MediaCrawler、XHS-Downloader、Obsidian 插件都不做 OCR）。我们不仅读图，还**逐张判断**：干货图转成可检索文字后**不再嵌图**（图和字不重复），界面截图、自拍风景图**保留**（它们本身就是信息）。目前唯一同路线的 xhs-claude-skills 只做"文字图 / 装饰图"二分流。
2. **评论两道筛** —— 同行要么不抓评论，要么整包抓（MediaCrawler 抓全量评论）。我们先按人过滤（只听博主本人的发言，「写不下了放评论区」的干货都在那儿），再按价值筛一道：干货补充留下，**"哈哈""想你了宝宝"这类寒暄直接丢**。
3. **先看再挑** —— 同行是"贴链接就导"或"列表全量下载"。我们先把博主主页铺成卡片，你点哪篇存哪篇。

把下面这段话直接发给你的 AI Agent（Claude Code / WorkBuddy / Cursor 都行），剩下的它代办：

### 1. 安装依赖

```bash
pip install -r requirements.txt
python -m playwright install chrome
```

### 2. 抓取笔记列表

```bash

```

或者按关键词发现：

```bash
python xhs_search_fetch.py --keyword "AI产品经理 面试" --count 40
```

### 3. 打开采集工作台

```bash
python xhs_picker_server.py
```

浏览器打开 `http://127.0.0.1:8788`，四个入口随意切换：

- **单篇导入**：粘贴分享链接或整段分享文字 → 解 析 → 抓取这篇，抓过的会自动识别
- **勾选**想保存的笔记（「全选未抓」一键跳过已抓的；勾选自动保存）
- **关键词搜索**：切到「关键词搜索」页，输入关键词直接搜，不用另开终端
- **开始抓取**：点左下角按钮，后台自动跑抓取脚本，日志实时可见，抓完卡片自动打「已抓过」
- **已抓笔记**：随时查看抓取进度，一键打开每篇的本地文件夹

### 4. 抓取正文与原图（也可用工作台里的「开始抓取」代替）

```bash

python xhs_fetch_selected.py --offset 5   # 接着往下抓（断点续导）
```

> 每张图一节 `## img_01.jpg` 后跟转录全文；**图内是长文干货的，逐字转录完整内容**（导出时这类图会自动转成文字、不再嵌图）；纯自拍/风景照片写 `（照片）`；界面截图只留关键内容和指令原文，跳过按钮和菜单。

### 🔧 技术原理

- **登录按需**：**单篇直抓走匿名通道，不用登录**（服务端渲染的页面里就有正文和原图）；**整号采集、关键词搜索、以及"要连博主评论一起存"的单篇导入**才需要登录态——Playwright 驱动真实 Chrome，扫码一次、本地持久化，不接触账号密码
- **不逆向签名**：直接读页面内存里的官方数据结构，避开加密参数逆向
- **列表双源采集**（整号/搜索）：首屏 SSR 直出数据 + 滚动加载的接口数据合并去重，**不漏最新一整屏**
- **评论两道筛**：先按人过滤（只听博主本人的发言），再按价值过滤（干货补充保留、寒暄短评丢弃）
- **断点续导**：中断后重跑自动跳过已完成笔记，适合分批、低频采集

## ❓ 常见问题

<details>
<summary><b>需要登录吗？会不会拿我的密码？</b></summary>

分情况：**单篇直抓（匿名通道）不用登录**；整号采集、关键词搜索、以及"要连博主评论一起存"的单篇导入需要登录，首次扫码一次、登录态本地复用。工具不接触账号密码，`browser_profile/` 已在 `.gitignore` 中排除，请勿提交到公开仓库。
</details>

<details>
<summary><b>会封号吗？</b></summary>

只做只读浏览（看主页、看搜索、看详情页），不做自动点赞、发布等写操作。但请自行控制频率，不要高频批量；搜索入口偶尔会触发风控导致页面一直转圈，隔一会儿再试即可。
</details>

<details>
<summary><b>抓一半断了怎么办？</b></summary>

直接重跑，已完成（`raw.json` 标记 ok）的会自动跳过。
</details>

<details>
<summary><b>能抓其他人的评论吗？</b></summary>

只抓博主本人发的评论——那通常是干货补充或追问回应；路人评论一概不收。
</details>

<details>
<summary><b>视频笔记呢？</b></summary>

优先抓平台官方字幕（`subtitle.srt`）——注意**平台只给部分视频生成字幕**，实测约三分之二有；没有字幕时抽关键帧，交给 OCR 那步一起处理（只认得出画面上的字，口播内容拿不到，会在笔记里标警告）。
</details>

<details>
<summary><b>为什么标题里的 emoji 没了？</b></summary>

默认去掉（导入 Obsidian 更干净），源码里可以关。
</details>

<details>
<summary><b>点开详情为什么弹出小红书登录框？</b></summary>

详情是嵌在内嵌视图里打开的，浏览器的跨站安全机制决定了它不带登录态。关掉登录框就能看笔记内容；要看评论等完整信息，点详情页左上角「浏览器打开↗」。这只影响"看"，不影响勾选和抓取。
</details>
