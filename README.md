## 📖 项目简介

**把小红书笔记可批量可单篇的挑着收进 Obsidian**：正文、图里的**干货文字**、博主本人在评论区的补充，一次抓干净。支持两种用法——

1. **主页批量**：把博主主页或搜索结果铺出来给你看，你点到哪篇存哪篇；
2. **单篇**：贴一个分享链接直接抓，不用登录。

和「贴链接就导」「全量下载」的工具不同，它在三个地方做了深加工：**图片逐张判断**——干货图转成可检索文字、不再嵌图（图和字不重复），界面截图和照片保留原样；**评论两道筛**——只听博主本人的发言，寒暄短评直接丢；**小标题自动还原**——`01｜xxx` 这类视觉标题变成 Obsidian 大纲里的真标题。最后按 Obsidian 规范落库，打开就能用。

**适合谁**：把小红书当信息源、需要长期沉淀到知识库的人（求职面经、行业经验、教程干货、竞品观察）。

## 📸 界面预览

![采集工作台](docs/images/picker.jpg)

工作台是一个本地网页，四个入口常驻同一页面：**博主主页 / 关键词搜索 / 单篇导入 / 已抓笔记**。

卡片式浏览，支持全选 / 反选 / 仅视频 / 仅图文 / 关键词过滤，抓过的笔记自动打「已抓过」标记；**点卡片 = 勾选**，**点标题或「原文↗」= 在内嵌详情页看原文**（按 `Esc` 或左上角「← 返回列表」回来，勾选不丢）。

**单篇导入**：粘贴分享链接（整段分享文字也行）直接发给ai让它帮忙一键解析抓取，抓过的会自动识别。

**长任务进度与控制（2026-10-22 上线）**：批量抓取时顶部实时显示结构化进度条（已处理 N/M、成功/失败/跳过、当前篇标题）；**停止是协作式的**——点「停止」后抓完当前篇就停，已完成内容全部保留，终态记为「已停止」而不是失败。任务结束后持久结果卡常驻页面：成功卡可打开保存位置、查看已抓笔记、一键复制「生成 Markdown」请求；部分完成卡可展开失败原因并**仅重试失败项**；新开页面不会串出历史任务卡。

### 这些事，同类项目大多没做

翻过上面几个同类型优质项目的源码和文档，这三处差异最明显：

1. **图里的字读出来，还做取舍** —— 同行普遍「只下载图、不识字」（MediaCrawler、XHS-Downloader、Obsidian 插件都不做 OCR）。我们不仅读图，还**逐张判断**：干货图转成可检索文字后**不再嵌图**（图和字不重复），界面截图、自拍风景图**保留**（它们本身就是信息）。目前唯一同路线的 xhs-claude-skills 只做"文字图 / 装饰图"二分流。
2. **评论两道筛** —— 同行要么不抓评论，要么整包抓（MediaCrawler 抓全量评论）。我们先按人过滤（只听博主本人的发言，「写不下了放评论区」的干货都在那儿），再按价值筛一道：**干货补充留下，"哈哈""想你了宝宝"这类寒暄直接丢**。
3. **先看再挑** —— 同行是"贴链接就导"或"列表全量下载"。我们先把博主主页铺成卡片，你点哪篇存哪篇甚至能点进去查看帖子详情。

### 🔧 技术原理

- **登录按需**：**单篇直抓走匿名通道，不用登录**——成功即产出 .md 文稿，入库走本地转换（不重抓；评论接口必须登录态，单篇匿名不含评论）；**整号采集、关键词搜索**才需要登录态——Playwright 驱动真实 Chrome，扫码一次、本地持久化，不接触账号密码
- **不逆向签名**：直接读页面内存里的官方数据结构，避开加密参数逆向
- **列表双源采集**（整号/搜索）：首屏 SSR 直出数据 + 滚动加载的接口数据合并去重，**不漏最新一整屏**
- **评论两道筛**：先按人过滤（只听博主本人的发言），再按价值过滤（干货补充保留、寒暄短评丢弃）
- **断点续导**：中断后重跑自动跳过已完成笔记，适合分批、低频采集

## 💻 在哪些环境里能用

**不绑定任何 Agent。** 本质是 5 个 Python 脚本 + 一个本地网页：

- 任何能执行命令的 AI Agent 都能用（Claude Code、Cursor、Codex CLI），或你自己开终端
- 勾选台就是普通网页（`http://127.0.0.1:8788`），在哪儿打开都行：系统浏览器标签页（推荐）、WorkBuddy 内嵌预览、VS Code / Cursor 的 `Simple Browser: Show`
- 服务只绑本机 `127.0.0.1`，同一 WiFi 下手机打不开（安全考虑）

## ❓ 常见问题

<details>

<summary><b>需要登录吗？会不会拿我的密码？</b></summary>

分情况：**单篇直抓（匿名通道）不用登录**——成功后直接产出 .md 文稿，要入库也是本地转换（不重抓、不登录；评论仅登录态可抓，单篇匿名不含评论）；整号采集、关键词搜索需要登录，首次扫码一次、登录态本地复用。工具不接触账号密码，`browser_profile/` 已在 `.gitignore` 中排除，请勿提交到公开仓库。

</details>

<details>

<summary><b>会封号吗？</b></summary>

只做只读浏览（看主页、看搜索、看详情页），不做自动点赞、发布等写操作。但请自行控制频率，不要高频批量；搜索入口偶尔会触发风控导致页面一直转圈，隔一会儿再试即可。

</details>

<details>

<summary><b>抓一半断了怎么办？</b></summary>

如果是主动点「停止」，系统会先结束当前篇，不再开始下一篇，并把已完成内容保留为「已停止」结果；可在结果卡继续抓取剩余笔记。若浏览器或进程意外中断，直接重跑即可，已完成（`raw.json` 标记 ok）的会自动跳过。

</details>

<details>

<summary><b>能抓其他人的评论吗？</b></summary>

只抓博主本人发的评论——那通常是干货补充或追问回应；路人评论一概不收。

</details>

<details>

<summary><b>视频笔记呢？</b></summary>

两层兜底：优先抓平台官方字幕（`subtitle.srt`）——注意**平台只给部分视频生成字幕**，实测约三分之二有；**没有字幕时自动下载视频、用本地 Whisper（faster-whisper）语音转写**，口播内容整段转成文字存进笔记（首次运行自动下载模型约 150MB，CPU 即可跑，纯 pip 安装不需要 ffmpeg）。不想要这一步可 `--no-asr` 关掉，只抽关键帧。

</details>

<details>

<summary><b>为什么标题里的 emoji 没了？</b></summary>

默认去掉（导入 Obsidian 更干净），源码里可以关。

</details>

<summary><b>点开详情为什么弹出小红书登录框？</b></summary>

详情是嵌在内嵌视图里打开的，浏览器的跨站安全机制决定了它不带登录态。关掉登录框就能看笔记内容；要看评论等完整信息，点详情页左上角「浏览器打开↗」。这只影响"看"，不影响勾选和抓取。

</details>
